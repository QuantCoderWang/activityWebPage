# activityWebPage

#### Description
这是一个独立于现有小程序商城之外的 Web 营销活动平台，用于开展“摇一摇抢券”类限时促销活动。用户通过链接直接参与活动，中奖后优惠券自动发放至其商城账户，与商城体系通过券模板和用户手机号打通，无需在商城侧做任何改动，即可实现外挂营销功能。
