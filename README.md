## 📖 简介

**车恒美活动抢券平台** 是一个外挂于现有小程序商城之外的 Web 版营销活动网站，主打「摇一摇抢券」玩法。

用户通过活动链接直接参与抽奖，中奖后优惠券通过国密加密通道自动发放至其商城账户；未注册用户会被引导扫码进入小程序完成注册，实现为商城持续引流。

### 项目亮点

- ⚡ **快速开活动**：后台几分钟配置一场活动，生成专属链接直接投放朋友圈、公众号、社群
- 🎲 **灵活玩法**：多奖品分级 + 概率抽奖 + 未中奖兜底，支持活动进行中动态调整概率和库存
- 🔐 **安全对接**：手机号 SM4 国密加密传输，发券异常自动回滚，前端 + 后端双重校验
- 🚀 **并发安全**：进程锁防止库存超发，限次限中奖防止刷券

## ✨ 功能一览

### 用户端

| 功能 | 说明 |
|---|---|
| 活动展示 | 图文介绍、奖品剩余/总库存实时更新 |
| 摇一摇抽奖 | 动画反馈 + 结果弹窗，手机号本地记忆免重复输入 |
| 自动发券 | 中奖后按手机号匹配，优惠券直达商城账户 |
| 注册引导 | 未注册用户弹出引导区，附小程序二维码 |
| 活动结束 | 奖品耗尽自动收起全部入口，仅显示结束提示 |

### 管理后台

| 功能 | 说明 |
|---|---|
| 活动管理 | 创建/配置活动代码、名称、多时段开放时间、每人抢券次数 |
| 图文编辑 | wangEditor 富文本编辑器，支持图片上传，随时修改 |
| 奖品配置 | 对接远程券库拉取券名，配置名次/概率/库存，概率合计自动校验 |
| 数据统计 | 抢券记录明细、参与人数（去重）、中奖统计 |
| 中途调整 | 库存（不低于已发出）、概率、图文，保存即时生效 |

## 📦 安装教程

### 环境要求

- Python 3.12+
- 可访问的远程商城数据库（用于注册校验与发券）

bash

1. 克隆仓库
git clone https://gitee.com/你的用户名/项目名.git

gunicorn -w 2 -b 0.0.0.0:8000 app:app # 生产环境
## 🚀 使用说明

### 管理员：创建活动

1. 浏览器访问 `http://你的域名/admin/login`，登录后台
2. 新建活动：填写活动代码、名称、开放时间段、每人最大抢券次数
3. 配置奖品：从远程券库选择券名，设置名次、中奖概率、库存（所有奖品概率合计不能超过 1，差额即为未中奖概率）
4. 编辑图文介绍（可选）
5. 保存后，将活动页链接 `http://你的域名/activity/<活动代码>` 投放给用户

### 用户：参与抢券

1. 打开活动链接，阅读图文介绍
2. 输入手机号，点击「🍹 摇一摇抢券」
3. 未注册用户按页面引导扫码注册后返回重试
4. 中奖后优惠券自动发放至商城账户，凭手机号到小程序内查看

### 活动中途调整

进入后台活动详情页，可直接修改库存（不可低于已发出数量）、中奖概率、图文说明，保存后即时生效，无需重启。


## ❓ 常见问题

<details>
<summary>概率合计必须等于 1 吗？</summary>

不需要。所有奖品概率合计不超过 1 即可，剩余概率自动成为「未中奖」的兜底概率。
</details>

<details>
<summary>库存能减少吗？</summary>

可以，但不能减少到低于已发出数量，前端和后端都有校验。
</details>

<details>
<summary>中奖了但券没到账怎么办？</summary>

发券失败时系统会自动回滚库存与中奖记录，用户可重新参与；请同时检查远程券库接口与商城库连接是否正常。
</details>
